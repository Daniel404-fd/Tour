# Трекер привычек и задач

Личное десктоп-приложение: привычки со стриками, задачи с дедлайнами и статистика.
Работает полностью локально, без интернета и аккаунтов.

## Быстрый старт (Windows)

Скачайте `HabitTracker.exe` и запустите двойным кликом — устанавливать Python ничего не нужно.
Файл можно положить куда угодно (например, в `C:\Program Files\HabitTracker` или на рабочий стол)
и закрепить на панели задач.

При первом запуске Windows SmartScreen может показать «Windows защитила ваш компьютер» —
у программы нет платной цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае».

## Запуск из исходников

### Требования

- Python 3.10 или новее
- PySide6 и cryptography

### Установка

```bash
python -m venv .venv
```

Активация окружения — Windows:

```bash
.venv\Scripts\activate
```

macOS / Linux:

```bash
source .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

### Запуск

```bash
python -m tracker.main
```

## Где хранятся данные

Все данные лежат в одной папке:

| Система | Папка |
|---------|-------|
| Windows | `%APPDATA%\HabitTracker` |
| macOS   | `~/Library/Application Support/HabitTracker` |
| Linux   | `~/.local/share/HabitTracker` |

* `tracker.sqlite3` — данные (или `tracker.htenc`, если задан пароль — тогда файл зашифрован);
* `backups\` — резервные копии; `settings.json` — настройки; `error.log` — журнал ошибок.

## Сохранность данных

* **Запись без порчи.** Каждое изменение сразу сохраняется: файл пишется целиком во временный,
  сбрасывается на диск и только потом заменяет старый. Если выключат свет посреди записи,
  останется предыдущая целая версия.
* **Ежедневные копии.** При первом запуске за день программа сохраняет копию в `backups`;
  хранятся последние 30. Перед восстановлением и сменой пароля делается страховочная копия.
* **Копия вне компьютера.** В «Настройки → Резервные копии» можно выбрать папку облачного диска
  (Яндекс Диск, OneDrive и т. п.) — копии будут уходить и туда и переживут поломку компьютера.
* **Проверка при запуске.** Если файл данных окажется повреждён, программа не откроет пустой
  список, а предложит восстановить данные из копии (повреждённый файл сохраняется рядом).
* **Одно окно.** Повторный запуск не открывает второе окно (два окна затирали бы изменения
  друг друга), а показывает уже открытое.
* **Восстановление** — «Настройки → Восстановить из копии…», можно выбрать и файл с флешки.

## Синхронизация с телефоном

Программа для ПК и приложение для Android обмениваются данными через ваш **Яндекс Диск**.
Каждое устройство пишет только свой файл в папку `HabitTracker-sync` и читает чужие;
при правке одной записи на двух устройствах побеждает более поздняя правка, удаления тоже
доходят. Сервера-посредника нет — данные идут только на ваш Диск.

1. Яндекс ID → Безопасность → **Пароли приложений** → «Файлы» — создайте пароль приложения
   (обычный пароль от Яндекса не подойдёт).
2. ПК: «Настройки → Синхронизация с телефоном» — логин, пароль приложения, имя устройства.
3. Телефон: «Ещё → Настройки» — те же логин и пароль приложения.

Синхронизация идёт сама: при запуске и закрытии, через 20 секунд после изменений и каждые
5 минут (на телефоне — при открытии, сворачивании и раз в час).

## Пароль

«Настройки → Установить пароль…». Пароль не просто закрывает окно: файл данных и резервные
копии шифруются (AES-256-GCM, ключ из пароля — scrypt). При установке пароля программа
показывает **код восстановления** — сохраните его отдельно от компьютера. Если забыть пароль,
войти можно по коду и задать новый; без пароля и без кода данные не откроет никто.
**Ctrl+L** — заблокировать программу, не закрывая её.

## Возможности

Слева — разделы; переключаться можно и клавишами **Ctrl+1…8**, новая запись в текущем разделе — **Ctrl+N**.
Оформление само следует светлой или тёмной теме Windows. В «Настройки → Оформление» можно выбрать
основной цвет, цвет отметок и прогресса, фон боковой панели (цвет или своя картинка с затемнением)
и тему; цвета подстраиваются так, чтобы текст оставался читаемым.

**Главная** — что важно сегодня: события календаря, привычки с отметкой в один клик, график за
14 дней, просроченные задачи и задачи со сроком на выбранный период (4 дня, неделя или две недели —
выпадающий список в карточке), прогресс целей и закреплённая заметка.

**Календарь** — как Google Календарь, только на вашем компьютере. Виды «день / неделя / месяц»
(клавиши D / W / M, стрелки — листать, T — сегодня). Создать событие — протянуть мышью по сетке
или дважды щёлкнуть по дню; перенести — перетащить; изменить длительность — потянуть за нижний
край. Несколько календарей со своими цветами (можно скрывать), события на весь день и на
несколько дней, повторы (каждый день / неделю по выбранным дням / месяц / год, с интервалом и датой
окончания). Повторяющееся событие можно изменить или удалить «только это», «это и следующие» или
«все». Напоминания приходят уведомлением Windows, пока программа открыта. Сроки задач тоже видны
в календаре. Масштаб сетки дня и недели — кнопки «−» / «+» вверху, **Ctrl+колесо мыши** или
**Ctrl+=** / **Ctrl+−** (**Ctrl+0** — обычный); выбранный масштаб запоминается.

**Привычки** — добавление, переименование, архив (с возвратом) и удаление. Отметку можно поставить
или снять за любой из последних 7 дней. Для каждой привычки — текущая серия, рекорд и полоса
последних 30 дней.

**Задачи** — название, описание, срок, приоритет, тема и **подзадачи**. Справа от списка — карточка
выбранной задачи: подзадачи там можно отмечать, добавлять (Enter), переименовывать двойным щелчком,
перетаскивать и удалять (Delete), не открывая окно задачи; в столбце «Шаги» видно, сколько сделано.
Темы (Дом, Работа, Учёба…) вы заводите сами через «Темы…». Фильтры по статусу и по теме; когда тем
больше шести, фильтр тем становится выпадающим списком с числом задач в каждой. Пробел — выполнено, Enter — изменить,
Delete — удалить, правый щелчок — все действия.

**Цели** — долгосрочные цели со сроком, описанием и шагами. Цель можно сделать **финансовой**:
указать, сколько нужно накопить, и записывать пополнения и снятия — программа покажет, сколько
осталось и сколько откладывать в месяц, чтобы успеть к сроку. Процент финансовой цели считается
по накоплениям, а если у неё есть шаги — поровну из накоплений и выполненных шагов.

**Заметки** — папки (создать, переименовать, удалить; заметку можно перетащить на папку или выбрать
папку в редакторе), поиск (Ctrl+F), автосохранение, закрепление.

**Настройки** — пароль, резервные копии, папка для копий в облаке, восстановление.

**Статистика** — выполнение привычек по дням за 4 недели, выполненные задачи по неделям,
разбивка выполненных задач по темам за 30 дней и сводка.

## Сборка .exe

На Windows с установленным Python 3.10+ запустите `build_windows.bat` — он создаст окружение,
установит зависимости, прогонит тесты и соберёт `dist\HabitTracker.exe` (настройки — в `HabitTracker.spec`).

## Тесты (для разработки)

```bash
pip install -r requirements-dev.txt
```

```bash
pytest
```

## Структура

```
tracker/
  main.py      — точка входа
  resources/   — иконка
  db.py        — схема SQLite и запросы
  logic.py     — серии, статистика, задачи, темы, цели, заметки (без Qt)
  storage.py   — надёжная запись на диск и шифрование
  backup.py    — резервные копии и настройки
  session.py   — пароль, копии, восстановление
  cal.py       — календарь: повторы, раскладка событий (без Qt)
  ui/          — главное окно и разделы; theme.py — цвета и стили, icons.py — иконки
tests/                — тесты логики и базы
run_app.py           — точка входа для сборки
HabitTracker.spec    — конфигурация PyInstaller
build_windows.bat    — сборка .exe на Windows
packaging/           — иконка .ico и сведения о версии для .exe
```
