# Трекер привычек и задач — ПК и Android

Одно приложение на двух устройствах: привычки, задачи по темам, календарь, цели
(в том числе финансовые), заметки по папкам. Данные синхронизируются через Яндекс Диск.

| Папка | Что внутри |
|---|---|
| `desktop/` | программа для Windows (Python + Qt), подробности — в `desktop/README.md` |
| `android/` | приложение для Android (Kotlin + Jetpack Compose) |
| `tools/interop.py` | проверка, что ПК и телефон понимают файлы синхронизации друг друга |

## Как получить готовые файлы

GitHub собирает всё сам при каждом изменении: вкладка **Actions** → последний запуск
**Android** или **Windows** → внизу раздел **Artifacts**:
`HabitTracker-android` (внутри `HabitTracker.apk`) и `HabitTracker-windows` (`HabitTracker.exe`).

### Установка на телефон

1. Скачайте `HabitTracker.apk` на телефон и откройте его.
2. Android спросит разрешение «Установка неизвестных приложений» для браузера или файлового
   менеджера — разрешите (приложение не из Google Play).
3. Обновления ставятся поверх, данные сохраняются (подпись у всех версий одна).

## Синхронизация

1. Яндекс ID → Безопасность → **Пароли приложений** → создать пароль для «Файлов».
2. ПК: «Настройки → Синхронизация с телефоном». Телефон: «Ещё → Настройки».
   Введите одинаковый логин и пароль приложения.

Каждое устройство хранит полную копию данных у себя и работает без интернета; на Диске
лежат файлы `device-*.json.gz` в папке `HabitTracker-sync`. Если одну запись изменили на обоих
устройствах — остаётся более поздняя правка.
